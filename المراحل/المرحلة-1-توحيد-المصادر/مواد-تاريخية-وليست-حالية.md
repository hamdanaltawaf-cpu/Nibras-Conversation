# YemReact — مواد تاريخية وليست حالية (Phase 1C)

> **تنبيه سياقي:** هذه وثيقة مصالحة تاريخية من المرحلة 1. توثق اختلاف الإصدارات وما كان متجاوزًا أو تجريبيًا وفق الأدلة المتاحة وقت إعدادها. لا تُستخدم لإثبات الحالة الحالية أو لإعادة فتح قرار أو استبداله؛ تُراجع المرجعية الكانونية وسجل القرارات الأحدث عند أي تعارض.

> **الغرض:** منع إعادة تقديم هذه المواد بوصفها حقائق حالية. فهي تمثل اختلافًا بين الإصدارات، أو نماذج أولية فقط، أو أمورًا استُبدلت صراحةً، أو منهجًا تاريخيًا، أو تفاصيل تنفيذ لم تعد تمثل القرار الحالي وقت إعداد هذا السجل.
> لا تعديل على الشيفرة أو Git أو قاعدة البيانات.

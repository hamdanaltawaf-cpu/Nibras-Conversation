## 2. منهجية وحدود التحقق

1. جرى التحقق من رأس `main` والشجرة الكاملة عند Commit الأساس أعلاه.
2. الشجرة لم تكن مبتورة؛ عُدّت الملفات والمجلدات من Git Tree الفعلي، لا من فهارس قديمة.
3. استُخدمت خريطة الملفات الحالية والوثائق التنظيمية والمرجعية وسجلات القرارات لتحديد الوظائف والسلطة، مع مراجعة مركزة لمحتويات الملفات المؤثرة والملفات التي وردت في التدقيق السابق.
4. فُحصت روابط Markdown المحلية في الملفات النصية التي جرى جلبها، كما فُحصت مواضع إحالات محلية مباشرة في ملفات HTML المختارة. النتيجة العددية المسجلة من الفحص السابق على لقطة الشجرة ذاتها: 35 رابط Markdown محلياً؛ 34 هدفاً موجوداً ورابط واحد مكسور.
5. لم تُقرأ كل ملفات الـ124 قراءة دلالية سطراً بسطر. التصنيف شامل على مستوى الجرد والمسار والوظيفة الموثقة، لكنه ليس تدقيقاً تحريرياً كاملاً لكل محتوى. لذلك وُسمت الحالات التي تحتاج مراجعة أعمق أو قرار المؤسس.
6. لم تُعاين الصور الـ17 بصرياً ولم تُشغّل ملفات HTML أو JSX؛ فُحصت أسماؤها ووجودها وامتداداتها، وبعض إحالاتها النصية فقط.
7. لا يُستنتج اعتماد قرار من اسم ملف أو وجوده أو نقله. القرار النافذ يُقرأ من المرجعية المختصة وسجل المصالحات.

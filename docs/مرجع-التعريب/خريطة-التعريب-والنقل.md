# خريطة التعريب والنقل — الخطوة الثامنة

> **الحالة:** مسودة خريطة مكتملة على مستوى الاقتراح؛ تنتظر مراجعة المؤسس واعتماد المسارات والأسماء قبل أي تنفيذ.
> **المستودع:** `hamdanaltawaf-cpu/Nibras-Conversation` — الفرع `main` — لقطة Git Tree: `5038334f9494b51d113adb005c8390eb7ccf2e14`.
> **الجرد الحالي المتحقق:** 125 ملفاً و15 مسار مجلد. يتضمن الجرد تقرير الخطوة السابعة الذي أُضيف بعد لقطة 124 ملفاً.
> **النطاق:** تحديد الوجهة والاسم المقترحين ونوع المعالجة لكل ملف. لا تنفذ هذه الوثيقة أي نقل أو إعادة تسمية أو ترجمة أو أرشفة أو حذف.

## 1. قواعد اعتماد الخريطة

- جميع الوجهات أدناه مقترحات وليست مسارات منشأة.
- المسارات العربية المقترحة للمجلدات مبنية على الهيكل الذي اعتمده المؤسس، مع تفكيك المجلدات المختلطة حسب نوع محتوياتها.
- أسماء معرفات القرارات والمراحل، وأسماء المنتجات والتقنيات، وامتدادات الكود والأصول، تبقى محمية.
- الأسماء العربية المقترحة للوثائق التفسيرية لا تغيّر معرفات القرار أو النصوص التاريخية.
- أي حالة لم يثبت مصيرها أو اسمها النهائي وُسمت بأنها تحتاج حسم المؤسس؛ لا يُنفذ عليها تخمين.
- حذف الملفات غير الفارغة غير مقترح في هذه الخريطة.

3. **جرد الصفحات والتدفقات:** اعتماد نقله إلى `حوكمة-المراحل/` واسمه العربي المقترح، مع التنبيه أن كلمة Draft في الاسم الحالي لا تثبت أن المحتوى غير مكتمل.
4. **الفهرس القديم 00_PROJECT_TAXONOMY_AND_FILE_MAP:** اعتماد أرشفته كفهرس تاريخي، وعدم حذفه.
5. **ملفات React:** اعتماد موضعها تحت `المراجع/نماذج-ومصادر-تقنية/` بدلاً من وضعها ضمن المواد النصية العادية؛ الاسم المقترح يحفظ الامتدادين `.jsx.md`.
6. **ملفات Manus ذات الامتداد المكرر:** اعتماد الأسماء العربية المقترحة وإزالة `.md.md` إلى `.md`، بعد فحص الإحالات.
7. **أصول HTML/PNG:** اعتماد جمعها في `المراجع/الأصول-المرئية/` مع إبقاء الأسماء الحالية؛ لا تُترجم أسماء الأصول ولا تعدّل ملفاتها.
8. **القرارات الكانونية وقرارات الهوية و5B:** اعتماد نقلها إلى المجلدات العربية مع إبقاء أسماء الملفات ومعرفاتها ومحتواها دون تغيير في دفعة النقل.
9. **مواد الفريق:** اعتماد الاسم النهائي للمجلد `فريق-يمن-رياكت/` وأسماء الملفات العربية المقترحة.

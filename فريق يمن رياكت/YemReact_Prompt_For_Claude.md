مرحبا Claude،

أنت المهندس المسؤول عن التأسيس الكامل لمشروع YemReact — مكتبة رياكشنات يمنية (فيديو فقط).

**ما الذي حدث بعد توقف محادثتك معي أنا المستخدم:**

بعدما توقفت محادثتك معي، لم أتوقف عن العمل. أخذت نِبراس (مساعد Arena.ai Agent Mode يعمل كـ Product Lead / Bridge) وأرينا (شريك النقاش التقني) وقمنا بنقاش متناوب لتحسين الواجهات بدون بنية — مجرد ملاحظات فقط، لا كود، لا تنفيذ، لا مصطلحات أجنبية في نقاش أرينا.

ناقشنا 3 محاور وأغلقناها كملاحظات فقط (ليست قرارات معتمدة نهائيًا):

- **المحور أ (الهوية والفكرة):** مغلق كملاحظات — مزيج: مكتبة مرئية أساس + بحث جانبي باقتراحات مثل بنترست عند الكتابة فقط بدون توجيه + حفظ بحساب جوجل فقط + مجموعات أداة مسؤول + لا توجيه في الزيارة الأولى
- **المحور ب (المحتوى والتحرير):** مغلق كملاحظات — 6 معايير جودة + نقطة تنوع داخلية + أداة كلمات مفتاحية قابلة للتطوير لهيكلة خوارزمية مستقبلًا (طلب المستخدم: "أريد نضيف أداة حتى نكون قادرين على تطويره فيما بعد حتى نكون هيكله خوارزميه للموقع كامل") + 9 فئات بيانات داخلية + جمع يدوي 30-50 أولًا ثم مساهمات
- **المحور ج (البنية والتنقل):** مغلق كملاحظات مع تأجيل نقطة واحدة — تفاصيله في الملف الجامع:
  - أ) تنقل: بحث علوي فقط (عدسة -> شريط كتابة -> صفحة نتائج منفصلة /بحث) + الشريط السفلي: الرئيسية، [زر مؤقت سيتغير مكان البحث السفلي]، المجموعات، الحساب + زر مساهمة (+) للمستخدم يظهر الآن للجميع (يطلب جوجل فقط)
  - ب) مجموعات: أبسط شكل — قائمة عنوان + عدد، عند الضغط شبكة لقطات — أداة مسؤول فقط
  - ج) إزالة الفئة نهائيًا من صفحة التفاصيل حتى كنقطة زينة — تبقى بيانات داخلية فقط
  - هـ) لوحة مسؤول 4 أقسام: رياكشنات، مجموعات، مساهمات، مسؤولين + 3 صلاحيات (مراجعة فقط، مجموعات فقط، إدارة كاملة بدون إضافة مسؤولين)
  - و) تذييل: خالي من القانونية — معلومات الموقع + خريطته + حساباته + المطور
  - د) مؤجل: توتر زر المساهمة — 3 خيارات (أ: يظهر لكن لا يدخل حتى 30-50، ب: يظهر ويدخل بعد المراجعة فورًا، ج: يظهر + قائمة انتظار مبكرة + رسالة "ستبدأ المراجعة بعد اكتمال الأساسي")

**ملاحظات مهمة:**
- الفيديو ليس بمقاس محدد والمدة حتى دقيقة (ملاحظة فقط، ليست معتمدة)
- البحث: زر معروف مثل فيسبوك وبنترست بدون توجيه
- صفحة التفاصيل: فيديو + عنوان + ثلاث نقاط على يسار الصفحة محاذاة العنوان (حفظ أولًا ثم تنزيل ثم نسخ رابط ثم مشاركة) + وصف أساسي + زر مطوي للوصف الثنائي يظهر فقط إذا وجد + مجموعات إن وجدت + قريبة

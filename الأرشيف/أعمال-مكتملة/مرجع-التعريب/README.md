# أرشيف مرجع التعريب

> **الحالة:** مكتمل ومغلق توثيقيًا بتاريخ 2026-11-28.

يحفظ هذا المجلد ملفات مشروع تعريب مستودع YemReact بعد اكتمال أعماله. نُقلت الوثائق من `الوثائق-التنظيمية/مرجع-التعريب/` دون تغيير متونها الأصلية، مع إضافة غلاف أرشيفي يوضح وضعها الحالي.

## محتويات الأرشيف

- `خطة-تنفيذ-تعريب-المستودع.md` — خطة العمل وبوابات الموافقة، محفوظة كسجل تاريخي لا كخطة نشطة.
- `خريطة-التعريب-والنقل.md` — خريطة النقل والتصنيف.
- `تدقيق-وتصنيف-الخطوة-السابعة.md` — تقرير التصنيف الأولي.
- `تقرير-فحص-الإحالات-والروابط-الخطوة-التاسعة.md` — تقرير فحص الإحالات والروابط.
- `تقرير-التحقق-النهائي-الخطوة-الثانية-عشرة.md` — تقرير الإغلاق وحدود التحقق النهائي.

## حدود الاستخدام

- هذا الأرشيف مرجع تاريخي للتتبع والاستدلال على ما نُفذ، وليس مصدرًا لقرارات المنتج.
- لا تُستأنف خطوات التعريب من هذه الوثائق إلا بتوجيه صريح جديد.
- لا تثبت تقارير التعريب تنفيذ التطبيق أو اختباره أو نشره.
- عند اختلاف أي وصف تاريخي مع حالة المستودع الحالية، تُقدّم الملفات والقرارات الحالية ضمن طبقات المرجعية المعتمدة.

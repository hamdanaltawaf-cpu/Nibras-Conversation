# أرشيف مقترحات Stage 5 غير المعتمدة والوثائق المتجاوزة

هذا المجلد يحفظ المواد الفريدة التي كانت موجودة في ثلاثة فروع تاريخية أُغلقت طلبات سحبها دون دمج. أُنشئ الأرشيف قبل حذف تلك الفروع حتى لا تضيع مادتها الفريدة.

## قواعد القراءة

- الملفات هنا **تاريخية فقط** وليست قرارات حالية أو مراجع تشغيلية.
- المقترحات غير المعتمدة لا تتحول إلى قرارات بمجرد أرشفتها.
- المسودات والنسخ التي استُبدلت لا تتقدم على وثائق `main` الحالية.
- لا تُستنتج من هذه المواد إعادة فتح Stage 5 أو إنشاء Stage 5.3 أو بدء Stage 6 أو Stage 9.
- إغلاق PR أو حذف فرع لا يعني قبول محتواه.

## حدود الحفظ

حُفظت النصوص الأصلية كاملة بعد إضافة تنبيه أرشيفي واضح في مقدمة كل نسخة. لا يعني هذا اعتماد محتواها، ولم تُنقل منها أي صياغة إلى الكانوني بوصفها قرارًا نافذًا. راجع سجل التغيير لمعرفة دفعة النقل والتحقق.

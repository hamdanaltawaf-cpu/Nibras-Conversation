# 05 — نظام التصميم ومكتبة المكونات

> **تنبيه سياقي:** هذه مواصفة مصدرية تاريخية محفوظة ضمن المواد المرفوعة. تصف تصورًا وحالة تقنية كما وردا وقت إعدادها، وقد تتعارض بعض تفاصيلها أو حالاتُها مع قرارات ومراجعات أحدث. لا تُعامل كمرجع canonical أو كدليل على وجود ميزة أو تنفيذ حالي، ولا تُنفّذ توصياتها اعتمادًا عليها وحدها. تُراجع المرجعية الكانونية والأدلة الأحدث قبل أي اعتماد.

## 5.6 قائمة التحقق لنظام التصميم (ما قال المصدر إنه يجب أن يتوافر قبل تسليم الواجهة)

- [x] تحديد رموز الألوان وقفلها (Brand v1.0).
- [x] تحديد عائلات الخطوط (Naskh للعربية وRoboto للإنجليزية) ومقياس الأحجام.
- [x] إعداد مقياس المسافات (شبكة 8 نقاط) كخصائص CSS مخصصة.
- [x] توثيق نقاط التوقف المتجاوبة (هاتف أقل من 700، ولوحي 700–1023، وسطح مكتب 1024 فأكثر).
- [x] توثيق جرد المكونات وخصائصها وحالاتها الافتراضية وسلوكها.
- [x] تحديد أساسيات الإتاحة: HTML دلالي، وسمات aria-*، ومؤشرات تركيز مرئية (من دون اختبار التباين وقتها).
- [x] منع أي عنصر واجهة من تجاوز رموز الهوية من دون قرار ACCEPTED صريح.

### البيان الختامي

تذكر الوثيقة أن نظام التصميم ومكتبة المكونات مستندان إلى الملفات المرفوعة آنذاك: ملف HTML للهوية المقفلة، ونماذج JSX وHTML، والتدقيق التقني. وكان الغرض منها توفير مرجع موحد للمصممين والمطورين، وفرض قواعد الهوية المقفلة، وتحديد المواصفات البصرية للمراحل التالية من إنتاج المحتوى وخارطة الطريق والإطلاق.

— ✅ **المرحلة 5 مكتملة وفق العبارة الواردة في الوثيقة الأصلية وقت إعدادها.** وكانت الوثيقة تطلب كتابة «المرحلة التالية» للانتقال إلى المرحلة 6 ضمن تسلسلها التاريخي؛ ولا يثبت ذلك حالة المراحل الحالية.

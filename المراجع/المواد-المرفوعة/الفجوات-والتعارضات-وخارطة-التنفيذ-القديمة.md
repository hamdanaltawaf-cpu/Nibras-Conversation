# 07 — تحليل الفجوات والتعارضات وخارطة التنفيذ القديمة

> **تنبيه سياقي:** هذه وثيقة تاريخية لتحليل الفجوات والتعارضات وخارطة التنفيذ، محفوظة ضمن المواد المرفوعة. تصف ادعاءات ومخاطر وتوصيات وحالات مراحل كما كانت وقت إعدادها، ولا تُعد جردًا للحالة الحالية أو مصدرًا للقرارات الحالية أو تفويضًا بتنفيذ أي بند. قد تكون البنود قد حُسمت أو تغيرت أو أصبحت متجاوزة؛ تُراجع المرجعية الكانونية وسجلات القرارات والأدلة الأحدث قبل أي اعتماد.

## الحكم النهائي في الوثيقة الأصلية (لقطة تاريخية)

| الفئة | نسبة الاكتمال كما وردت | المبررات التي أوردتها الوثيقة |
|---|---:|---|
| الأساس (Foundation) | 90% | TypeScript صارم، وlint/prettier بلا أخطاء، وبناء ناجح، وAppError/env/http موحدة. |
| الواجهة الخلفية (API) | 80% | 23 معالج مسار مع Zod وحراس وسجل تدقيق؛ مع نقص طبقة الخدمات وتحديد المعدل ونقاط الدفعات. |

| المصادقة | 80% | Google وJWT ودور قاعدة البيانات تعمل مع مستخدمين حقيقيين؛ بلا إدارة أدوار وبإعدادات افتراضية غير آمنة. |
| الوسائط | 35% | منطق كامل محليًا (216 تشغيلًا)، لكن لا قدرة إنتاجية بسبب غياب ffmpeg والتخزين المحلي وحد الطلب. |
| لوحة المسؤول | 70% | CRUD للرياكشنات والفئات والمجموعات والمساهمات؛ بلا واجهة Featured أو Users أو Audit، وبلا ترقيم صفحات. |

| تجربة الاستخدام (UX) | 55% | تدفقات الزائر والمستخدم والمسؤول موجودة؛ لا Settings ولا اقتراحات، ومجموعات TTL، وثلاثة قوالب تنقل. |
| الواجهة (UI) | 60% | تطبيق Brand v1.0 وRTL والتجاوب دون تجاوز أفقي؛ CSS أحادي كبير، ولوحة المسؤول خام، واختلاف عن النموذج الأولي. |
| الاختبارات | 60% | 171 اختبار وحدة و94 اختبار E2E تنجح وفق المصدر؛ و94 اختبار تكامل و30 اختبار E2E غير قابلة للتشغيل (قاعدة البيانات/ffmpeg). |
| النشر | 40% | Vercel وNeon للقراءة والمصادقة يعملان؛ الوسائط متعذرة، والبيئة غير واضحة، ولا يوجد vercel.json. |

**الحالة العامة للمشروع كما قدرتها الوثيقة:** نحو 60% (متوسط مرجح بحسب المصدر).

**العوائق الرئيسية كما وصفتها:** خط معالجة الوسائط (P0)، ونظافة Git (P0)، وفصل البيئة (P1)، وBUG‑1 (P1).

ويذكر المصدر أن موافقة المالك («تم») على ميزات MVP الإلزامية، وحل عوائق P0/P1 — ولا سيما عامل الوسائط وفصل البيئات — كانا شرطين للانتقال إلى جاهزية إطلاق تقديرية تقارب 90%. هذه أرقام تاريخية ولا تمثل قياسًا للحالة الراهنة.

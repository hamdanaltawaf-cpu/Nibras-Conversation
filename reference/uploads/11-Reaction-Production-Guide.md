# YemReact — Reaction Production Guide

دليل تنفيذي واحد يكفي لإنتاج رياكشن من الصفر حتى النشر، بدون الرجوع لأي مرجع ثانٍ. مبني فوق YemReact Brand v1.0 LOCKED — لا قرارات جديدة هنا، فقط خطوات تنفيذ.

---

## 1. اختيار اللقطة
ابحث في مصادر خام (فيديوهات طويلة، لقاءات، بودكاست، بث قديم) عن لحظة تُفهم بذاتها بدون سياق. فحص سريع: لو صاحبك استلمها بدون أي شرح، هل يفهمها في ثانية؟ إذا لا، تجاوزها.
فحص أخلاقي إلزامي: شخص عادي قد يتضرر من الانتشار؟ مصدر مدفوع/محمي بوضوح؟ أي "نعم" = استبعاد فوري.

## 2. قصّها
ابدأ لحظة واحدة قبل الذروة، انتهِ فور انتهائها — بلا مقدمة، بلا هبوط بطيء. المدة الطبيعية 2–6 ثوانٍ (حتى 8 للسخرية/الإحراج البطيء). **ممنوع أي Intro أو شعار متحرك قبل اللقطة — أول فريم = بداية الرياكشن.**

## 3. اختيار التصنيف
اسأل: "لو وصلتني هذي اللقطة من غير سياق، أول كلمة تجيني ببالي؟" — تلك هي الفئة. لا تفكر أكثر من ثانيتين.

| الفئة | Hex | الفئة | Hex |
|---|---|---|---|
| ضحك | `#F4C430` | رفض | `#6E8296` |
| صدمة | `#7C5CFF` | سخرية | `#D98E04` |
| غضب | `#C81E3A` | حماس | `#E8712E` |
| استغراب/انبهار | `#2CB6C4` | موافقة | `#4CAF6D` |
| إحراج/صمت | `#F17FB2` | | |

## 4. Default أو Mirrored؟
شاهد اللقطة كاملة مرة واحدة. لو دخلت يد أو حركة الزاوية العلوية اليمنى (مكان التقشّر الافتراضي) في أي لحظة → استخدم **Mirrored**. غير ذلك → **Default**. القرار يشمل الكتلة كاملة (تقشّر + تاغ المدة) دفعة واحدة، لا عنصرًا واحدًا لوحده.

## 7. "لمّا..." أم الاقتباس المباشر؟
- **الاقتباس المباشر**: اللقطة قوية بذاتها، الجملة داخلها تكفي (مثال: "يا ساتر!"). هذا الافتراضي لأغلب المنشورات.
- **"لمّا..."**: اللقطة تجاوب على موقف يومي محدد يحتاجه الناس تحديدًا (منشورات "متى تحتاجها؟"). استخدمها بصيغة موقف حقيقي قصير، لا وصف عام.
- لا تخلط الصيغتين في نفس المنشور.

## 8. متى لا نضع نصًا إطلاقًا
لو التعبير نفسه يوصل المعنى كامل بدون الحاجة تسمع الصوت أو تفهم كلمة — لا تضف أي كابشن داخل الفيديو. خلي نقطة التصنيف تكفي كإشارة، والسياق يعيش في نص المنشور خارج الفيديو فقط. إضافة نص لمعنى واضح أصلاً = شرح للنكتة، وهذا ممنوع بقواعد العلامة.

## 9. طريقة التصدير
1. قص اللقطة النهائية بأي برنامج مونتاج (CapCut، Premiere، DaVinci، أو حتى تطبيق الهاتف).
2. صدّر/جهّز الكانفاس بنفس مقاس الـOverlay بالضبط: 1080×1920 (عمودي) أو 1080×1080 (مربّع).
3. أضف ملف الـOverlay المطابق كطبقة صورة علوية، Stretch-to-fit كامل الإطار (0 إزاحة، 100% حجم) — الملف مُجهّز مسبقًا بنفس أبعاد الكانفاس تمامًا، فلا حاجة لأي تعديل موضع.
4. أضف دائرة تصنيف صغيرة (~1.2% من عرض الإطار) فوق تاغ التصنيف الفارغ، بلون الفئة من جدول القسم 3.
5. اكتب رقم المدة داخل التاغ الفارغ (خط بسيط، أرقام فقط، مثال "3s").
6. صدّر الفيديو النهائي بنفس المقاس، H.264 mp4.

## 10. فحص الجودة قبل النشر
- [ ] الصوت نظيف وواضح
- [ ] التقشّر/الواترمارك ظاهر وما يغطيه شي
- [ ] لا عنصر تصميمي يلمس الوجه أو التعبير
- [ ] المدة على التاغ صحيحة
- [ ] نقطة التصنيف باللون الصحيح من الجدول
- [ ] الكابشن (إن وُجد) يطابق قاعدة واحدة فقط من القسم 7
- [ ] لا مقدمة قبل أول فريم

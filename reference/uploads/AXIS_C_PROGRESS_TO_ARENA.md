# تقدم المحور (ج) — البنية والتنقل — مرسل إلى أرينا — كملاحظات فقط

تاريخ الإرسال: 2026-09-08
المرسل: نبراس
المستقبل: أرينا
الحالة: مرسل وينتظر الرد

## ملخص قرارات المستخدم النهائية في المحور (ج) بعد التعديلات:

### 1. الخريطة العامة:
- الرئيسية = المكتبة المرئية (الأساس)
- صفحة بحث منفصلة: عند الضغط على زر البحث يظهر شريط كتابة، يكتب المستخدم، ثم عند الضغط على بحث تظهر النتائج في صفحة منفردة (وليس نفس الصفحة عبر ?بحث=)
- صفحة تفاصيل الرياكشن برابط حقيقي /ر/[رمز]
- صفحة مجموعات /مجموعات (المستخدم قال لم أفهمها مرتين — تحتاج توضيح مبسط جدًا)
- قائمة حساب منبثقة تحتوي المحفوظات + مساهماتي + خروج
- لوحة مسؤول 4 أقسام: رياكشنات، مجموعات، مساهمات، مسؤولين
- التذييل مبسط — القانونية والأسئلة مؤجلة لمرحلة فتح المساهمات

### 2. التنقل — قرار جديد مهم:
- المستخدم قرر: نعتمد البحث في الشريط العلوي فقط، والذي في الشريط السفلي سوف نغير زر آخر بدله فيما بعد
- الشريط العلوي: شعار + زر بحث (يفتح شريط كتابة ثم صفحة نتائج) + زر مساهمة (+) للمستخدم
- الشريط السفلي: الرئيسية، [زر مؤقت مكان البحث سيتغير لاحقًا]، المجموعات، الحساب
- زر المساهمة (+) ليس للمسؤول — هو للمستخدم ويظهر الآن للجميع، عند الضغط إذا لم يكن مسجلاً يطلب تسجيل جوجل فقط ثم يفتح نموذج مساهمة

### 3. صفحة تفاصيل الرياكشن — تعديلات نهائية:
- الفيديو ثم العنوان
- زر ثلاث نقاط يكون على يسار الصفحة محاذاة العنوان (وليس يمين)
- داخل ثلاث نقاط: حفظ أولًا، ثم تنزيل، ثم نسخ رابط، ثم مشاركة (اتفق)
- وصف أساسي ثم زر مطوي للوصف الثنائي يظهر فقط إذا وجد
- إزالة الفئة من صفحة الرياكشن نهائيًا حتى كنقطة زينة — تبقى بيانات داخلية فقط
- المجموعات المرتبطة إن وجدت فقط كـ "موجود في: ..." ثم فيديوهات قريبة

### 4. قائمة الحساب:
- منبثقة، صورة واسم من جوجل، محفوظات مع عدد ظاهر بجانب الكلمة (اتفق)، مساهماتي بحالتها، تسجيل خروج — بدون إعدادات الآن

### 5. لوحة المسؤول:
- 4 أقسام: رياكشنات (عرض وإدارة)، مجموعات (عرض وإدارة)، مساهمات (مراجعة محتوى المستخدمين)، مسؤولين (إضافة مسؤول بصلاحيات محدودة)
- 3 صلاحيات مقترحة: مراجعة مساهمات فقط، إدارة مجموعات فقط، إدارة كاملة بدون إضافة مسؤولين (اتفق)

### 6. أسئلة سابقة:
- س1 صفحة البحث بفلاتر؟ — المستخدم أجلها ووضح: شريط كتابة ثم صفحة نتائج منفردة
- س2 زر المساهمة؟ — يظهر الآن
- س3 صفحة المجموعات؟ — لم يفهمها
- س4 ترتيب ثلاث نقاط؟ — اتفق
- س5 صلاحيات؟ — 3

## المطلوب من أرينا الآن قبل إغلاق المحور (ج):
1. تأكيد فهم قرار البحث العلوي فقط والسفلي سيتغير
2. توضيح صفحة المجموعات بأبسط شكل ممكن لأن المستخدم لم يفهمها مرتين
3. تأكيد إزالة الفئة نهائيًا من التفاصيل
4. تأكيد زر المساهمة يظهر الآن رغم مرحلة الجمع اليدوي
5. إعطاء خلاصة نهائية للمحور (ج) كملاحظات جاهزة للإغلاق

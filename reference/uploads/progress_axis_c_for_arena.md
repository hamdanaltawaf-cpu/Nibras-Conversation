# عرض تقدم المحور (ج) على أرينا قبل الإغلاق — كملاحظات فقط

## ملخص ما تم الاتفاق عليه مع المستخدم بعد جولتين:

**1. الخريطة العامة:**
- الرئيسية = المكتبة المرئية (الأساس)
- صفحة بحث منفصلة /بحث: عند الضغط على زر البحث يظهر شريط كتابة، يكتب المستخدم، ثم عند البحث تظهر النتائج في صفحة منفردة (هذا ما أكده المستخدم)
- صفحة تفاصيل الرياكشن /ر/[رمز] برابط حقيقي
- صفحة المجموعات /مجموعات (المستخدم لم يفهمها — تحتاج توضيح بسيط)
- قائمة الحساب منبثقة تحتوي المحفوظات + مساهماتي + خروج
- لوحة مسؤول 4 أقسام: رياكشنات، مجموعات، مساهمات، مسؤولين
- التذييل مبسط — القانونية والأسئلة مؤجلة لمرحلة فتح المساهمات

**2. التنقل — تعديل مهم جديد:**
- المستخدم قرر: نعتمد البحث العلوي، والذي في الشريط السفلي سوف نغير زر آخر بدله فيما بعد
- إذًا: الشريط العلوي: شعار + زر بحث (يفتح شريط كتابة ثم صفحة نتائج منفصلة) + زر مساهمة (+) للمستخدم يظهر الآن للجميع
- الشريط السفلي: الرئيسية، [زر مؤقت مكان البحث سيتغير لاحقًا]، المجموعات، الحساب — البحث الآن أساسه في العلوي فقط
- زر المساهمة (+) يظهر الآن للجميع، عند الضغط إذا لم يكن مسجلاً يطلب تسجيل جوجل فقط ثم يفتح نموذج المساهمة

**3. صفحة تفاصيل الرياكشن — تعديلات المستخدم الأخيرة:**
- الفيديو ثم العنوان
- زر ثلاث نقاط يكون على يسار الصفحة محاذاة العنوان (وليس يمين)
- داخل ثلاث نقاط: حفظ أولًا، ثم تنزيل، ثم نسخ رابط، ثم مشاركة — اتفق
- وصف أساسي ثم زر مطوي للوصف الثنائي يظهر فقط إذا وجد
- إزالة الفئة من صفحة الرياكشن نهائيًا (حتى نقطة الزينة) — قرار جديد
- المجموعات المرتبطة إن وجدت فقط ثم فيديوهات قريبة

**4. قائمة الحساب:**
- اتفق على إظهار عدد المحفوظات بجانب كلمة المحفوظات

**5. لوحة المسؤول:**
- اتفق على 4 أقسام و 3 صلاحيات: مراجعة مساهمات فقط، إدارة مجموعات فقط، إدارة كاملة بدون إضافة مسؤولين

**6. أسئلة أرينا السابقة وإجابات المستخدم:**
- س1 صفحة البحث بفلاتر؟ — المستخدم: لم توضح لي الفكرة نأجلها — ثم وضح: عند الضغط يظهر شريط كتابة ثم تظهر النتائج في صفحة منفردة
- س2 زر المساهمة؟ — يظهر الآن للجميع
- س3 صفحة المجموعات؟ — لم يفهمها — تحتاج توضيح مبسط جدًا
- س4 ترتيب ثلاث نقاط؟ — اتفق
- س5 صلاحيات المسؤولين؟ — 3 صلاحيات

**المطلوب من أرينا الآن كملاحظات فقط قبل إغلاق المحور (ج):**
1. تأكيد فهم التعديل الجديد: البحث يعتمد في العلوي، السفلي سيتغير زر البحث لاحقًا لزر آخر
2. توضيح صفحة المجموعات بأبسط شكل ممكن لأن المستخدم قال "لم أفهمها" مرتين
3. تأكيد إزالة الفئة نهائيًا من صفحة التفاصيل (حتى كنقطة زينة) — هل هذا مقبول كملاحظة؟
4. تأكيد أن زر المساهمة (+) يظهر الآن رغم أن الجمع اليدوي 30-50 لم يكتمل — هل هذا يسبب إرباك؟
5. إعطاء خلاصة نهائية للمحور (ج) كملاحظات مجمعة جاهزة للإغلاق

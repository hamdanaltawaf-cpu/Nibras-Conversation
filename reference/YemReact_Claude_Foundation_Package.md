## 1. ملخص سريع للوصول الحالي

**المشروع:** YemReact — مكتبة رياكشنات يمنية — فيديو فقط (مقتطع من مواقف يمنية حقيقية، يُفهم بذاته بدون سياق) — الشعار التشغيلي "خذها. حطها. يمنية." — الرياكشن = المثل الشعبي الرقمي

**الهوية:** Brand v1.0 LOCKED (قُصاصة، ألوان القشر، Lalezar/Cairo، Watermark مقوى، قاعدة قلب الكتلة) — لا إعادة تصميم

**الملاحظة المهمة الجديدة:** المستخدم نبه أن الافتراض السابق "9:16 + 1:1 ثابت و 2-8 ثواني" غير دقيق — الآن كملاحظة: الفيديو ليس بمقاس محدد، والمدة حتى دقيقة كحد أقصى — للمناقشة فقط، ليست معتمدة

**الهدف الحالي:** إطلاق Facebook بـ 30-50 فيديو حقيقي متنوع كحد أدنى اختبار، 150-300 عتبة فائدة — + خطة منتج قابلة للتسليم لمصمم ومطور

**آلية العمل:** نقاش متناوب — نِبراس مع المستخدم مرة، ثم مع أرينا مرة — محور واحد في كل مرة — لا بناء — لا مصطلحات أجنبية في نقاش أرينا — ملاحظات فقط حتى كلمة "تم" من صاحب المشروع

**المحاور السبعة A-G:**
- أ: الهوية والفكرة (Core) — مغلق كملاحظات
- ب: المحتوى والتحرير — مغلق كملاحظات
- ج: البنية والتنقل (IA) — مغلق كملاحظات مع تأجيل نقطة د
- د: تجربة التفاعل — التالي + نقطة د المؤجلة
- هـ: نظام تقني فكرة فقط
- و: نمو وأعمال
- ز: تشغيل وصيانة

## 2. المحور أ — الهوية والفكرة — مغلق كملاحظات — خلاصة مجمعة

**ما اتفقنا عليه مع المستخدم وأرينا:**

- جوهر الفكرة: مزيج — المكتبة المرئية أساس، البحث جانبي مساعد، الاكتشاف محدود
- البحث: جانبي، المستخدم يعرف ماذا يكتب، نساعده باقتراحات مثل بنترست عند الكتابة فقط، بدون توجيه إضافي — زر بحث معروف مثل فيسبوك وبنترست
- الرئيسية: مكتبة مرئية، البحث ثنائي بنفس طريقة بنترست
- المجموعات: ليست أساسية، ينشئها المسؤول وتبدأ بالظهور، وعند النشر خيار اختياري للإضافة
- الحد الأدنى: 30-50 فيديو حقيقي متنوع + بحث جانبي باقتراحات + حفظ يتطلب حساب جوجل فقط + صفحة تفاصيل برابط حقيقي
- المقاس والمدة: ملاحظة فقط — ليس بمقاس محدد والمدة حتى دقيقة
- الحساب: تسجيل دخول جوجل فقط
- التوجيه: لا حاجة لتوجيه في الزيارة الأولى — زر البحث معروف

## 3. المحور ب — المحتوى والتحرير — مغلق كملاحظات — خلاصة مجمعة

**ما اتفقنا عليه:**

- معنى المحتوى الجيد: 6 معايير (تعبير واضح، مفهوم بذاته، موقف واضح، أصالة يمنية، جودة مقبولة، ملاءمة) + نقطة داخلية للتنوع + أداة قابلة للتطوير لهيكلة خوارزمية مستقبلًا (S1: المستخدم قال "لم أفهم طريقة النظام ولكن أريد نضيف أداة حتى نكون قادرين على تطويره فيما بعد حتى نكون هيكله خوارزميه للموقع كامل" — تم تأكيد نعم)
- أنواع المحتوى: 3 أنواع مع تغيير أولوية: عند الحاجة أولًا، مكتبة الأسبوع ثانيًا، اليومي ثالثًا ويمكن تأجيله
- التصنيف: 9 فئات ثابتة كبيانات داخلية + كلمات مفتاحية مفتوحة كبيانات داخلية فقط للبحث الجانبي، بدون عرضها كفلتر للمستخدم — المجموعات أداة تنظيم للمسؤول فقط
- مصدر المحتوى: جمع يدوي من المسؤول أولًا 30-50، ثم فتح المساهمات لاحقًا عند وجود دليل سلوكي — المبدأ متفق، التفاصيل الرقمية لم تحسم (S5: المستخدم لا اتفق مع ملاحظة الدليل السلوكي لفتح المساهمات — يحتاج بديل)
- التنوع: تتبع داخلي فقط للتوازن، بدون فلتر للمستخدم (S3 اتفق)
- التكرار: تكرار الملف نفسه = رفض، نفس الموقف بأداء مختلف = قبول بشرط الأصالة (S2 اتفق، S4 اتفق على تأجيل اليومي)

**ملفات أرينا للمحور ب:**
- ملخص 6 إجابات + جدول مقارنة + رأي مبدئي manual-first hybrid + 5 أسئلة S1-S5 (نظام كلمات مفتاحية، معايير تكرار مكتوبة، نسب تنوع، يومي، تعريف دليل سلوكي) — موجودة في المحادثة كـ inline وليس ملف منفصل

## 4. المحور ج — البنية والتنقل — مغلق كملاحظات مع تأجيل نقطة د — خلاصة نهائية بعد 3 جولات

**أ) التنقل — تم:**
- البحث علوي فقط (زر عدسة في الشريط العلوي -> يظهر شريط كتابة -> عند البحث تظهر النتائج في صفحة منفردة /بحث) — ليس نفس الصفحة عبر ?بحث=
- الشريط السفلي: الرئيسية، [زر مؤقت مكان البحث السفلي سيتغير لاحقًا لزر آخر]، المجموعات، الحساب — البحث السفلي ملغى ويستبدل لاحقًا (المستخدم قرر: "نعتمد العلوي الذي في الشريط السفلي سوف نغير زر اخر بدله فيما بعد")
- زر مساهمة (+) للمستخدم يظهر الآن للجميع في الشريط العلوي — عند الضغط إذا لم يكن مسجلاً يطلب تسجيل جوجل فقط ثم يفتح نموذج مساهمة

**ب) المجموعات — تم — بعد أن قال المستخدم "لم أفهمها" مرتين:**
- أبسط شكل: قائمة بالمجموعات، كل مجموعة عنوان + عدد لقطات، عند الضغط تظهر لقطات المجموعة بنفس تنسيق المكتبة المرئية
- المجموعات أداة تنظيم للمسؤول فقط، المستخدم لا ينشئها، تظهر في التفاصيل كـ "موجود في: ..." إن وجدت فقط
- توضيح أرينا: مثل ألبومات يصنعها المسؤول فقط

**ج) إزالة الفئة نهائيًا من التفاصيل — تم:**
- الفئة مزالة نهائيًا من صفحة التفاصيل حتى كنقطة زينة — تبقى بيانات داخلية فقط للبحث الجانبي وتنظيم المسؤول (المستخدم: "ازالة الفئة من صفحة الرياكشن نهائيا")

**د) توتر زر المساهمة — مؤجل للمحور التالي — نقطة خلاف:**
- الخيار أ: زر يظهر لكن المحتوى لا يدخل حتى 30-50 — مرفوض من المستخدم — "لا اتفق دعنا نناقشه"
- الخيار ب: زر يظهر + المحتوى يدخل بعد المراجعة + يدوي + مساهمات متزامنة من البداية — قيد النقاش "نناقشه"
- اقتراح ثالث (ج) من نِبراس: زر يظهر الآن + قائمة انتظار مبكرة + رسالة واضحة "ستبدأ المراجعة بعد اكتمال الأساسي 30-50" + حالة المساهمة في حساب المستخدم
- الحالة: مؤجل للمحور د — تجربة التفاعل

**هـ) لوحة المسؤول — نعم:**
- 4 أقسام: رياكشنات (عرض وإدارة)، مجموعات (عرض وإدارة كألبومات: اسم + عدد + غلاف)، مساهمات (مراجعة 40/ساعة بنفس أداة 6 معايير + تنوع + كلمات مفتاحية قابلة للتطوير)، مسؤولين (إضافة مسؤول بصلاحيات محدودة: مراجعة مساهمات فقط، إدارة مجموعات فقط، إدارة كاملة بدون إضافة مسؤولين) — 3 صلاحيات — تم

**و) التذييل — تعديل جديد:**
- خالي من القانونية (الشروط والخصوصية والأسئلة مؤجلة/ملغاة حسب طلب المستخدم — سابقًا كانت مؤجلة، الآن المستخدم قال: "التذييل خالي من القانونية نجعل فيه معلومات الموقع وخريطته وحساباته والمطور")
- يحتوي: معلومات الموقع + خريطة الموقع + حسابات الموقع الاجتماعية + معلومات المطور

**تفاصيل إضافية مؤكدة:**
- صفحة البحث المنفصلة: حقل كبير + اقتراحات عند الكتابة مثل بنترست + شبكة نتائج + حالة فارغة مشجعة — بدون فلاتر الآن (مؤجلة)
- صفحة تفاصيل الرياكشن: فيديو، عنوان + زر ثلاث نقاط على يسار الصفحة محاذاة العنوان (ترتيب داخلي: حفظ أولًا ثم تنزيل ثم نسخ رابط ثم مشاركة)، وصف أساسي، زر مطوي للوصف الثنائي يظهر فقط إذا وجد (إذا لم يوجد لا يظهر الزر)، مجموعات مرتبطة إن وجدت ثم فيديوهات قريبة — بدون فئة نهائيًا
- قائمة الحساب: منبثقة، صورة واسم من جوجل، محفوظات مع عدد ظاهر، مساهماتي بحالتها (قيد الانتظار/مقبولة/مرفوضة)، تسجيل خروج — بدون إعدادات الآن
- الشريط العلوي: شعار + بحث + مساهمة (+) للمستخدم — زر المسؤول في صفحة الإدارة فقط (المستخدم صحح: "ليس للمسؤول بل هذا للمستخدم زر المساهمة زر المسؤول في صفحة الادمن ليس هنا")
- الشريط السفلي: الرئيسية، [زر مؤقت سيتغير]، المجموعات، الحساب

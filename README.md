# YemReact — مستودع المشروع

هذا المستودع هو مساحة توثيق وتنظيم مشروع **YemReact**: مكتبة رياكشن يمنية قصيرة ومنتقاة، وليست شبكة اجتماعية أو موجزاً عاماً. يحتوي المستودع على المرجعية الحالية وقرارات المنتج وسجلات الحوكمة والمواد التاريخية والمراجع وأصول الهوية ومواد الفريق.

> **تنبيه الحالة:** وجود قرار أو مواصفة أو نموذج داخل المستودع لا يثبت أن الميزة نُفذت أو اختُبرت أو نُشرت. تُقرأ حالة التنفيذ من أدلتها الصريحة، ولا تُستنتج من الوثائق التصميمية.

## ابدأ من هنا

1. اقرأ [دليل قراءة المستودع](docs/دليل-قراءة-المستودع.md) لفهم ترتيب المرجعيات وكيفية فض التعارض.
2. راجع [خريطة الملفات](docs/خريطة-الملفات.md) لمعرفة محتويات المستودع ومساراتها ووظائفها.
3. راجع [سياسة التسمية واللغة](docs/سياسة-التسمية-واللغة.md) لفهم قواعد اللغة والأسماء والاستثناءات التقنية.
4. راجع [سجل إعادة التنظيم](docs/سجل-إعادة-التنظيم.md) لمعرفة ما نُفذ فعلياً من تغييرات تنظيمية.
5. للرجوع إلى أدلة الفحص وسياق مراجعة بنية المستودع، افتح [وثيقة التدقيق](docs/تدقيق-هيكل-المستودع-وأسماء-الملفات.md).

## أقسام المستودع الحالية

| المسار | الغرض العام |
|---|---|
| `canonical/` | المرجعية الكانونية وقرارات المنتج وسجل القرارات. |
| `stage-1-source-reconciliation/` | سجلات المصالحة والتعارضات والمجهولات التاريخية. |
| `stage-2-reformation/` | خطة إعادة التشكيل وسجلات حوكمة وإغلاق التوثيق. |
| `stage-4-identity/` | قرارات الهوية ومواد النقاش والنماذج المرتبطة بها. |
| `stage-5-ia-navigation/` | قرارات ومناقشات بنية المعلومات والتنقل. |
| `docs/` | الوثائق التنظيمية والتدقيق ومرجع سير التعريب. |
| `reference/` | المواد المصدرية والمرفوعة والمرئية. |
| `archive/` | المواد التاريخية والقرارات المتجاوزة والمقترحات المحفوظة. |
| `فريق يمن رياكت/` | وثائق تعريف وتسليم مواد الفريق. |

هذه خريطة وصفية للشجرة الحالية، وليست إعلاناً بأن الهيكل العربي المستهدف قد نُفذ. أسماء المجلدات الحالية ستظل كما هي حتى استكمال خطوات التصنيف وخريطة النقل وفحص الإحالات واعتمادها.

## مبادئ القراءة والعمل

- القرار المعتمد ضمن نطاقه هو المرجع الموضوعي، ولا يحل README أو دليل القراءة أو خريطة الملفات محله.
- المقترحات والمواد التاريخية لا تصبح قرارات بمجرد وجودها في المستودع.
- لا تغيّر هذه الوثائق أي قرار منتج أو حالة مرحلة.
- لا يبدأ نقل الملفات أو إعادة تسميتها أو حذفها قبل استكمال بوابات الموافقة المحددة في [خطة تنفيذ تعريب المستودع](docs/مرجع-التعريب/خطة-تنفيذ-تعريب-المستودع.md).

## نطاق هذا المستودع

المستودع يوثق YemReact وقراراته وتاريخه وتنظيم مواده. أما تعريب واجهة التطبيق أو RTL أو تنفيذ خصائص التطبيق فهي أعمال منفصلة لا يثبتها إنشاء هذه الوثائق التنظيمية.

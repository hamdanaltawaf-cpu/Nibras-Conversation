# YemReact — مستودع المشروع

هذا المستودع هو مساحة توثيق وتنظيم مشروع **YemReact**: مكتبة رياكشن يمنية قصيرة ومنتقاة، وليست شبكة اجتماعية أو موجزاً عاماً. يحتوي المستودع على المرجعية الحالية وقرارات المنتج وسجلات الحوكمة والمواد التاريخية والمراجع وأصول الهوية ومواد الفريق.

> **تنبيه الحالة:** وجود قرار أو مواصفة أو نموذج داخل المستودع لا يثبت أن الميزة نُفذت أو اختُبرت أو نُشرت. تُقرأ حالة التنفيذ من أدلتها الصريحة، ولا تُستنتج من الوثائق التصميمية.

## ابدأ من هنا

1. اقرأ [دليل قراءة المستودع](الوثائق-التنظيمية/دليل-قراءة-المستودع.md) لفهم ترتيب المرجعيات وكيفية فض التعارض.
2. راجع [خريطة الملفات](الوثائق-التنظيمية/خريطة-الملفات.md) لمعرفة محتويات المستودع ومساراتها ووظائفها.
3. راجع [سياسة التسمية واللغة](الوثائق-التنظيمية/سياسة-التسمية-واللغة.md) لفهم قواعد اللغة والأسماء والاستثناءات التقنية.
4. راجع [سجل إعادة التنظيم](الوثائق-التنظيمية/سجل-إعادة-التنظيم.md) لمعرفة ما نُفذ فعلياً من تغييرات تنظيمية.
5. للرجوع إلى أدلة الفحص وسياق مراجعة بنية المستودع، افتح [وثيقة التدقيق](الوثائق-التنظيمية/تدقيق-هيكل-المستودع-وأسماء-الملفات.md).

|---|---|

| `المراحل/المرحلة-2-إعادة-التشكيل/` | الخطة الرئيسية لإعادة التشكيل. |

| `المراجع/المواد-المرفوعة/` | المواد المصدرية والمرفوعة التاريخية، بما فيها وثائق الرؤية والمواصفات والتسليمات المرجعية. |

| `archive/` | المواد التاريخية والقرارات المتجاوزة والمقترحات المحفوظة. |
| `فريق-يمن-رياكت/` | وثائق تعريف وتسليم مواد الفريق. |

هذه خريطة وصفية للشجرة الحالية. أُنجزت دفعات النقل التنظيمي حتى الدفعة 19؛ ما زالت الخطوة 10 مستمرة لبقية الخريطة، ولم يبدأ تعريب محتويات الوثائق (الخطوة 11).

## مبادئ القراءة والعمل

- القرار المعتمد ضمن نطاقه هو المرجع الموضوعي، ولا يحل README أو دليل القراءة أو خريطة الملفات محله.
- المقترحات والمواد التاريخية لا تصبح قرارات بمجرد وجودها في المستودع.
- لا تغيّر هذه الوثائق أي قرار منتج أو حالة مرحلة.
- تُنفذ عمليات النقل وفق خريطة النقل المعتمدة وعلى دفعات صغيرة، مع تحديث الإحالات والتحقق. راجع [خطة تنفيذ تعريب المستودع](الوثائق-التنظيمية/مرجع-التعريب/خطة-تنفيذ-تعريب-المستودع.md).

## تنظيم ملفات Stage 4

- `المراحل/المرحلة-4-الهوية/` — أصول الهوية والنقاشات والقرارات، مع الحفاظ على معرفات DECISION-I.

## نطاق هذا المستودع

المستودع يوثق YemReact وقراراته وتاريخه وتنظيم مواده. أما تعريب واجهة التطبيق أو RTL أو تنفيذ خصائص التطبيق فهي أعمال منفصلة لا يثبتها إنشاء هذه الوثائق التنظيمية.

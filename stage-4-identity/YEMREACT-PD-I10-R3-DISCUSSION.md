## 1 · قائمة الحساب

| | متكيّف | Sheet للاثنين |
|---|---|---|
| Desktop | Popover | Sheet غريب |
| Mobile | Sheet | نفس الشيء |

**التوصية:** المتكيّف.

**المحتوى:**

**اعتراضات:**
- "المحفوظات" مكررة (Header + Bottom Nav) — تُحذف من القائمة
- "مساهماتي" بلا معنى قبل الإطلاق — تُخفى
- الإعدادات للزائر أيضًا (جهاز لا حساب)

## 3 · Empty / Loading / Error

**(أ) Empty:**
- هادئ، مركزي
- Lucide icon في حاوية دائرية
- عنوان + سطر ثانوي + إجراء واحد
- **/saved:** "لا محفوظات بعد" + "اضغط ♡ على أي رياكشن" + [تصفح المكتبة]
- **بحث فارغ:** "لا نتائج لـ «…»" + Masonry من المكتبة تحته
- **قاعدة:** لا Empty State بلا مخرج
- **لا Qussasa** في Empty (تجنب Anchor رابع)

**(ب) Loading:**
- Skeleton للمحتوى + Spinner 16px للأزرار
- Skeleton Masonry بنسب متفاوتة (منع Layout shift)
- البحث السريع: Skeleton فقط إذا تجاوز 300ms

**(ج) نبرة الخطأ:**
- فصحى مبسطة، هادئة
- Network: "تعذّر الاتصال" + "إعادة المحاولة"
- 500: "حدث خطأ من جهتنا"
- 404: "لم نعد نجد هذا الرياكشن" + "العودة إلى المكتبة"

**(د) Emojis:** Lucide فقط في UI

**اعتراض على Q15:** Toast للنجاح فقط = الفشل صامت. اقتراح: **Toast خطأ أيضًا** (أيقونة تحذير محايدة).

**إضافة:** Failed media (سطح رمادي + أيقونة باهتة) — حالة ناقصة.

## 4 · شريط البحث

**التوصية: B**
- Desktop: حقل 44px، عرض 420-480px، بلا Pill، بلا حجم Pinterest الضخم
- Mobile: أيقونة → عند الضغط حقل كامل (أو حقل كامل مباشرة)
- Placeholder: "ابحث عن رياكشن أو موقف..."
- **بلا فلاتر في v1**
- اقتراحات عند التركيز: بحث حديث + مجموعات

**نقطتان:**
- Chips غير قابلة للنقر → **البحث هو الطريق الوحيد لإيجاد شخصيات**. يجب أن يفهرس اسم الشخصية والوصف والوصف الثنائي
- **النتائج حالة من صفحة المكتبة (`?q=`) وليست صفحة رابعة**
